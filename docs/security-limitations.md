# 安全边界与已知限制

## 安全边界

- 来源配置、文档库目录和 Extension 代码属于**可信的本机配置**。不要让不可信项目或模型任意修改配置或 `PI_KNOWLEDGE_*` 环境变量。
- 远端文档内容始终是不可信参考数据，不是系统指令。工具说明和返回值会提醒模型这一点；仍应审查来源，不执行文档中要求运行的命令。
- 网络获取只发生在安装/更新阶段，下载和 Git 仅允许 HTTPS；下载拒绝降级重定向。
插件不承诺提供网络 SSRF 沙箱：可信配置仍可指向内网 HTTPS 地址，需要时应使用系统网络策略限制。
- 压缩包不使用 `extractall`；逐项校验并复制，拒绝绝对路径、`..`、反斜线/盘符路径、软硬链接和特殊文件。本地导入拒绝符号链接，不执行脚本。
- 下载或本地压缩包最大 150 MiB；来源成员累计最大 600 MiB、最多 30000 个文件、单文件最大 20 MiB。
- Git 使用浅克隆、不抓取子模块、禁用交互凭据和全局/系统配置，并设置超时。但 Git 克隆过程本身没有硬磁盘配额，只应安装可信仓库；导入快照仍受文件限额约束。
- 后端调用使用 argv/stdin JSON，不拼接 shell 命令。Pi 调用支持 AbortSignal、240 秒超时及输出上限；下载 socket 超时为 60 秒，Git 超时为 180 秒。
- 管理命令持有 POSIX 文件锁；SQLite 使用 WAL 和事务；失败时清理临时快照。不要对不可信 SQLite 库执行操作。

## 已知限制

1. 不是网站爬虫，不处理 JS 动态渲染文档、PDF 或 EPUB；只支持 UTF-8（解码错误会替换）。
RST 是保留源码的轻量解析，不做 Sphinx 构建或跨文件 include 展开，复杂表格和层次结构可能不完美。
2. 版本识别范围有限，不解析 pnpm/yarn/Bun/Cargo/Go 锁文件、Conda、旧式 Poetry 配置、动态依赖或传递依赖树差异；也不自动向上寻找 monorepo 根目录。
可在正确子项目启动 Pi，或人工确认后指定版本。未识别不等于已确认。
3. FTS5 不具备语义检索或同义词能力；标点会被分词，未命中不能证明 API 不存在。中文连续文本没有专门分词支持，建议使用 API 名称或英文关键词。
4. 配置声明的版本/来源由维护者负责，插件不能自动证明下载内容与声明版本一致。Git 分支和标签可能变化，建议审核记录的 commit 与下载校验值。
5. 每次查询都会启动 Python 进程；安装和重建是全量操作。适合本地中小型文档库，不提供增量抓取、压缩归档保留、自动垃圾回收或后台更新。
索引期间不要手动修改库快照。
6. 插件不提供宿主机 OS 级沙箱，也不能绝对消除模型的提示注入风险。Windows 原生写操作没有支持或验证，建议使用 WSL。
